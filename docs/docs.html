Überblick

Foxly MOTD zeigt beim SSH-Login kompakte Systeminformationen.

Voraussetzungen

  • Debian oder Ubuntu mit systemd und pam_motd
  • Bash, Zsh oder Fish als Login-Shell (Warp SSH auf allen dreien unterstützt)
  • APT-basierte Paketverwaltung; Docker und lolcat optional

Installation

  1. 1

    Schnellinstallation ausführen.

    bash
    curl -fsSL https://motd.foxly.de/install.sh | sudo bash
  2. 2

    Installation, Timer und Ausgabe prüfen.

    bash
    foxly-motd status
foxly-motd preview
systemctl list-timers 'foxly-motd-*'

Konfiguration

Die Einstellungen liegen unter /etc/default/foxly-motd.

Bestehende Werte bleiben bei Updates erhalten.

Betrieb und Updates

bash
foxly-motd check-update
sudo foxly-motd update
sudo foxly-motd rollback
sudo foxly-motd uninstall

Der Standardmodus informiert über neue Releases.

Migration

Der Installer sichert erkannte Legacy-Skripte vor der Migration.

Sicherheit und Hilfe

Release-Archive werden geprüft und vor dem Austausch gesichert.
