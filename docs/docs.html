und sicher betreiben.

Von der ersten SSH-Anmeldung bis zum sicheren Update: Diese Dokumentation führt durch Installation, Konfiguration, Migration und täglichen Betrieb.

01 · Überblick

Systemstatus beim ersten Blick

Foxly MOTD zeigt beim SSH-Login kompakte Systeminformationen.

Schneller LoginKeine Paket- oder Netzwerkanfragen im Login-Pfad.
Klare DiagnoseNetzwerk, Ressourcen und Dienste in einem kompakten Raster.

02 · Voraussetzungen

Bevor du beginnst

  • Debian oder Ubuntu mit systemd und pam_motd
  • Bash, Zsh oder Fish als Login-Shell (Warp SSH auf allen dreien unterstützt)
  • APT-basierte Paketverwaltung; Docker und lolcat optional
Warp SSHDer Installer richtet die zusätzliche Anzeige für Bash, Zsh und Fish automatisch ein und erhält Warps Eingabeeditor, Blöcke und Vervollständigung.

03 · Installation

In wenigen Minuten startklar

  1. 1

    Schnellinstallation ausführen.

    bash
    curl -fsSL https://motd.foxly.de/install.sh | sudo bash
  2. 2

    Installation, Timer und Ausgabe prüfen.

    bash
    foxly-motd status
foxly-motd preview
systemctl list-timers 'foxly-motd-*'

04 · Konfiguration

Das Dashboard passend einstellen

Die Einstellungen liegen unter /etc/default/foxly-motd.

MOTD_LANGUAGEAutomatische Sprache, Deutsch oder Englisch.
SHOW_*Module und Detailbereiche einzeln ein- oder ausblenden.
COLOR_MODEFarbausgabe dauerhaft aktivieren oder deaktivieren.
UPDATE_MODEÜber Releases informieren oder automatisch aktualisieren.
UpdatesicherBestehende Werte bleiben bei Updates erhalten.

05 · Betrieb

Prüfen, aktualisieren, zurückrollen

bash
foxly-motd status
foxly-motd preview
foxly-motd check-update
sudo foxly-motd update
sudo foxly-motd rollback
sudo foxly-motd uninstall

Der Standardmodus informiert über neue Releases.

06 · Migration

Alte Installation sicher übernehmen

Der Installer sichert erkannte Legacy-Skripte vor der Migration.

Eigene SkripteNicht erkannte Dateien bleiben erhalten. Prüfe sie vor einer erzwungenen Migration mit --migrate-legacy force.

07 · Sicherheit und Hilfe

Nachvollziehbare Releases

Release-Archive werden geprüft und vor dem Austausch gesichert.

SHA-256Downloads werden vor der Installation geprüft.
RollbackVor einem Upgrade wird der installierte Stand archiviert.
